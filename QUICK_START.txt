🆘 TROUBLESHOOTING
================================================================================

Problem: Server won't start
  $ docker-compose logs web | tail -20
  → Check error messages
  → Common: Syntax error or migration issue
  → Fix: docker-compose down -v && docker-compose up --build

Problem: Tests failing
  $ python manage.py test tests.test_suite --verbosity=2
  → See detailed error messages
  → Common: Database connection issue
  → Fix: docker-compose down -v && docker-compose up --build

Problem: Dashboard shows 0 items
  → Are you logged in as COMMERCIAL role?
  → Check: User roles in Django admin
  → Fix: Add COMMERCIAL role to user

Problem: Can't validate payment (404 error)
  → Payment status must be 'enregistre' (not 'valide')
  → Only 'enregistre' items can be validated
  → This is by design - prevents double-validation

Problem: Échéance not auto-generating
  → Check: Caution payment status is 'valide'?
  → Check: Signal log in Django admin → JournalAudit
  → Verify: CommercialPaymentValidateView was called

All problems? → See DEPLOYMENT.md [Troubleshooting] for more solutions
